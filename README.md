## 📖 About The Project

**"Are you a Tritium Christian?"** is a responsive, aesthetically striking web page hosting a sermon delivered by James Sopok at Glidewell Baptist Church. 

The design takes inspiration from the sermon's core metaphor: **Tritium (H3)**—a radioactive isotope that glows continuously from an internal energy source, without needing external light to "charge" it. The UI reflects this with a sleek dark mode, pulsing neon-green animations, and smooth scroll reveals.

---

## :sparkles: Features

* 🌒 **Immersive Dark Theme**: Deep dark backgrounds (`#0f1115` and `#1a1d24`) that make the text and accents pop.
* 🧪 **Tritium Glow Animations**: Custom CSS `@keyframes` create a pulsing, glowing vial effect right in the hero section.
* 📜 **Scroll Animations**: Utilizes the vanilla JavaScript `IntersectionObserver` API to trigger smooth, cascading fade-in effects as the user scrolls down the page.
* 📱 **Fully Responsive**: Adapts seamlessly to mobile phones, tablets, and desktop monitors.
* 🎨 **Modern Typography**: Beautifully paired Google Fonts (*Montserrat* for headings, *Open Sans* for body text).

## :book: The Message

The webpage elegantly presents three core truths about being a "Tritium Christian" in a dark world:

1. **Our power source is internal, not external.** 
   *We don't rely on the environment to shine; the Holy Spirit provides an internal glow.*
2. **The darker the room, the brighter the light.** 
   *Darkness isn't a threat—it's an opportunity to do exactly what we were made to do.*
3. **It’s a steady, lasting light.** 
   *Not a flashing firecracker, but a quiet, steady, enduring glow.*

## :hammer_and_wrench: Tech Stack

This project is built to be lightweight and fast, requiring zero dependencies or build tools.

* **HTML5**: Semantic structure and layout.
* **CSS3**: Native CSS Variables (`:root`), Flexbox, Gradients, and Keyframe Animations.
* **Vanilla JavaScript**: Lightweight scroll-triggered animations.
